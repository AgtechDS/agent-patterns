## [0.1.0] - 2026-07-24

### Added
- GitHub Gardener: pattern dev per manutenzione repository
- Decision Journal: pattern life per tracciamento decisioni e bias
- Debug Diary: pattern dev per diario strutturato di bug
- Dotfiles Curator: pattern dev per analisi dotfile
- Server Sentinel: pattern dev per monitoraggio servizi
- LLM Wiki: pattern knowledge per wiki persistente
- Reading Companion: pattern knowledge per companion libri
- Study Companion: pattern knowledge per studio e spaced repetition
- Health Timeline: pattern life per storia medica centralizzata
- Personal CRM: pattern life per gestione relazioni
- Life Admin: pattern life per documenti e scadenze
- Finance Narrator: pattern life per narrazione finanziaria
- Meeting Memory: pattern work per estrazione decisioni da meeting
- Project Postmortem: pattern work per retrospettive strutturate
- World Bible: pattern creative per mondi narrativi
- TEMPLATE.md: standard canonico per ogni pattern
- CONTRIBUTING.md: guida contribuzione con 5-criteria filter
- `.github/ISSUE_TEMPLATE/`: template per new-pattern, bug-report, improvement
- `.github/PULL_REQUEST_TEMPLATE.md`: template per PR
- `examples/decision-journal/`: esempio realistico con 5 decisioni su 6 mesi
- `examples/github-gardener/`: esempio realistico con snapshot e report

### Changed
- Decision Journal v1.1: arricchito con Tipo, Stato emotivo, Confidenza, Hindsight bias check, Modalità fallback
