# Decision Journal — Esempio di output

Questo è un esempio di ciò che il Decision Journal produce su 6 mesi di decisioni reali. I dati sono realistici ma non reali.

Per usare il pattern sul tuo progetto:
1. Copia [`patterns/life/decision-journal/SCHEMA.md`](../../patterns/life/decision-journal/SCHEMA.md) nel tuo agent
2. Digita `dj init` per creare `.journal/` e la struttura
3. Inizia con `dj log` per registrare la tua prima decisione
