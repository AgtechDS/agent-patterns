# GitHub Gardener — Esempio di output

Questo è un esempio di ciò che il GitHub Gardener produce su una repository fittizia **acme-api**. I dati sono realistici ma non reali.

Per usare il pattern sul tuo progetto:
1. Copia [`patterns/dev/github-gardener/SCHEMA.md`](../../patterns/dev/github-gardener/SCHEMA.md) nel tuo agent
2. Digita `garden init` per creare `.garden/` e il primo snapshot
3. Esplora le operazioni: `garden triage`, `garden prune`, `garden audit`, `garden report`
