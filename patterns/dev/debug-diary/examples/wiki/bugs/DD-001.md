# DD-001: GET /users timeout dopo 30s

**Data:** 2026-06-15
**Sistema:** Backend API (Node.js + PostgreSQL)
**Impatto:** API bloccata, utenti vedevano errore 504
**Tempo speso:** 3h

## Sintomi
- Endpoint `GET /api/users` andava in timeout dopo esattamente 30s
- Solo su dataset con >1000 utenti
- In staging non riproducibile (pochi dati)

## Causa radice
N+1 query: per ogni utente, una query separata per caricare i ruoli. Con 1000 utenti → 1001 query.

## Fix
Aggiunto `include: ['roles']` eager loading con JOIN. Query singola.

## Verifica
Test con 5000 utenti: response time passato da 30s a 200ms.

## Prevenzione
Aggiunta regola nel linter: `detect-n-plus-one` in CI.
